## 📖 О проекте

RustyGit — нативное десктоп-приложение на [Rust](https://rust-lang.org/) и [eframe](https://github.com/emilk/egui/tree/master/crates/eframe), которое оборачивает привычные Git-операции в быстрый и приятный интерфейс. Никаких Electron webview — только нативный рендер и фоновые потоки, поэтому даже под нагрузкой UI остаётся отзывчивым.

## ✨ Что уже есть

### 🌿 Ветки (Branches)
- Список локальных и удалённых (`origin/...`) веток одним списком.
- Переключение (checkout) в один клик; чекаут `origin/feature` автоматически создаёт локальную копию с трекингом.
- Создание новых веток с опцией немедленного перехода.
- Удаление веток с подтверждением в диалоговом окне.
- Отображение upstream-связей (`main → origin/main`).

### 📝 Изменения и коммиты (Changes)
- Раздельные секции: **Staged**, **Unstaged** и **Untracked** файлы.
- Индексация/снятие для отдельных файлов (`[+]` / `[-]`) или всех сразу (`Stage All` / `Unstage All`).
- Откат изменений (`Discard`) и удаление untracked-файлов — с защитным подтверждением.
- Многострочное поле сообщения коммита, опция **Amend**, отправка коммита по **Ctrl+Enter**.

### 🔍 Просмотр диффов (Diff Viewer)
- Нумерация строк и цветовая подсветка:
  - 🟩 добавления (зелёный фон),
  - 🟥 удаления (красный фон),
  - 🟦 заголовки блоков `@@ ... @@`,
  - контекстные строки кода.
- Статистика `+N / -N` по каждому файлу.

### 📜 История коммитов (History)
- Полный лог: короткий хэш, автор, дата, тема.
- Мгновенный поиск и фильтрация по подстроке (автор, хэш, сообщение).
- Детальная карточка коммита: полный хэш, автор, описание (summary + body), список файлов и полный дифф.

### 📂 Инспектор файлов (Files)
- Обзор дерева файлов репозитория.
- Просмотр исходников с номерами строк прямо в приложении.

### 🌐 Синхронизация (Remote Sync)
- **Push / Pull / Fetch** одной кнопкой с панели инструментов.
- Все сетевые операции выполняются в фоне (отдельные потоки + MPSC-канал) — интерфейс никогда не зависит от сети.
- Результаты и ошибки — в нижней строке состояния.

### 🧰 Прочее
- Открытие любого репозитория через диалог папок, создание нового (`git init`) в пустой папке.
- Тёмная тема «Warm Graphite» с янтарным акцентом; все цвета, отступы и иконки собраны в одном месте (`src/theme.rs`).
- Векторные иконки (epaint strokes) без внешних библиотек, шрифт JetBrains Mono для кода и хэшей.

## ⌨️ Горячие клавиши

| Сочетание  | Действие                                |
|------------|------------------------------------------|
| `F5`       | Обновить состояние репозитория           |
| `Ctrl + O` | Открыть другой репозиторий               |
| `Ctrl + 1` | Вкладка **Changes**                      |
| `Ctrl + 2` | Вкладка **Branches**                     |
| `Ctrl + 3` | Вкладка **History**                      |
| `Ctrl + 4` | Вкладка **Files**                        |
| `Ctrl + Enter` | Сделать коммит (в поле сообщения)    |

## 🚀 Сборка и запуск

### Требования
- [Rust и Cargo](https://rustup.rs/) (1.85+, edition 2024)
- Установленный [Git](https://git-scm.com/) в `PATH`

```bash
# Режим разработки
cargo run

# Оптимизированная релизная сборка
cargo build --release
```

Готовый бинарник: `target/release/rusty_git.exe` (Windows) или `target/release/rusty_git` (Linux/macOS).

## 🏗 Архитектура

| Модуль | Ответственность |
|--------|-----------------|
| `src/models.rs` | Модели данных: `Branch`, `FileStatus`, `CommitInfo`, `DiffLine`, `ParsedDiff` |
| `src/git.rs` | Вызовы Git CLI (с подавлением консольных окон на Windows) |
| `src/diff_parser.rs` | Парсер unified diff: типы строк, номера старой/новой версии, hunks |
| `src/app.rs` | Главное окно, реактивный UI на egui, фоновые операции, модальные окна |
| `src/theme.rs` | Дизайн-токены: палитра, метрики, иконки, виджеты |
| `src/main.rs` | Точка входа, конфигурация окна eframe |
